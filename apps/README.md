# Apps

Esta pasta contém as diferentes interfaces do Lema.

## `web-design-prototype`

**Não é o produto final.** É um protótipo front-end mockado (dados locais, sem backend), usado exclusivamente pelo time de design (Lethicia) para validar arquitetura da informação, navegação, fluxos e experiência antes da implementação real — ver regras completas em `CLAUDE.md` ("Contexto de trabalho — Front-end protótipo do Lema"). Nenhum código dele será reaproveitado na implementação real.

## Aplicações futuras (nenhuma criada ainda)

- `web` — a implementação real do produto (stack a definir/em definição — ver decisões técnicas em `docs/architecture/`), construída do zero a partir dos casos de uso, jornadas e das telas aprovadas (`APPROVED FOR DEV`) do protótipo, não a partir do código dele.
- mobile;
- home-hub;
- whatsapp-bot.

Todas devem, sempre que possível, acessar o mesmo domínio e fonte central de dados.
