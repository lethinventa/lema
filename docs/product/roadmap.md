# Roadmap

> Este roadmap é exploratório. Ele representa hipóteses de evolução do produto, não compromissos definitivos de escopo ou prazo.

## MVP

O objetivo do MVP é validar a proposta central do Lema: é útil organizar vida pessoal e compartilhada dentro do mesmo sistema?

Inclui:

- autenticação;
- usuários;
- grupos/família;
- sistema de privacidade e compartilhamento;
- Home / Hoje;
- tarefas;
- calendário;
- objetivos;
- finanças básicas.

## V2

Possibilidades:

- alimentação;
- planejamento de refeições;
- listas de compras;
- organização da casa;
- manutenção doméstica;
- documentos;
- despesas recorrentes;
- orçamentos mais avançados;
- lançamentos financeiros sugeridos automaticamente;
- bot no WhatsApp;
- Central do Lar para tablet compartilhado.

## Lançamentos financeiros automáticos

Registrado aqui como visão futura: a possibilidade de detectar movimentações através de notificações bancárias.

Exemplo de notificação:

> "Compra aprovada de R$ 84,90 em Supermercado XYZ."

O Lema poderia interpretar:

- valor;
- estabelecimento;
- data;
- cartão/conta;
- categoria provável;
- contexto provável.

E sugerir:

> "Registrar R$ 84,90 em Mercado → Família?"

Inicialmente, priorizar o fluxo **detectar → sugerir → usuário confirmar**.

Não está definido ainda como essa integração será tecnicamente implementada.

## WhatsApp

O WhatsApp pode funcionar como uma interface rápida para interagir com o Lema.

Exemplos:

- "Gastei 72 reais no mercado."
- "Adiciona café e leite na lista."
- "Quanto gastamos com mercado esse mês?"
- "O que tenho para fazer hoje?"
- "Coloca pagar internet para sexta."

O bot deve acessar a mesma fonte de dados do produto principal.

## Central do Lar

Prever uma interface específica para um tablet compartilhado em uma área comum da casa, como cozinha ou sala.

Ela deve priorizar informações compartilhadas, como:

- tarefas da família;
- compromissos;
- cardápio;
- lista de compras;
- lembretes;
- contas próximas;
- informações da casa;
- objetivos compartilhados.

Essa interface não deve ser apenas uma versão ampliada do aplicativo principal. Ela deve ser desenhada especificamente para:

- consulta rápida;
- leitura à distância;
- ações simples;
- uso compartilhado.

Informações privadas nunca devem aparecer nela por padrão.

## Futuro

Possibilidades:

- automações;
- aprendizado de padrões;
- regras automáticas;
- integrações externas;
- recomendações;
- sugestões proativas;
- entrada de informações por diferentes canais;
- redução progressiva de registros manuais.
