# Definition of Done

Uma feature pode ser considerada concluída quando, quando aplicável:

- atende aos critérios de aceite do caso de uso;
- implementação real está integrada;
- mocks temporários foram removidos ou claramente identificados;
- estados de loading foram tratados;
- estados vazios foram tratados;
- erros relevantes foram tratados;
- permissões e visibilidade foram validadas;
- comportamento responsivo foi verificado;
- UX foi validada;
- documentação foi atualizada se o comportamento final mudou;
- não existem problemas conhecidos críticos.

## Done de Produto

Fluxo e experiência validados.

## Done de Engenharia

Implementação funcional e integrada.

## Done da Feature

Produto + engenharia concluídos e integrados.
