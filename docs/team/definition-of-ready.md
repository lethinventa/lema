# Definition of Ready

Uma feature está pronta para desenvolvimento quando, quando aplicável:

- possui caso de uso identificado;
- objetivo está claro;
- ator está definido;
- fluxo principal está documentado;
- regras de negócio principais estão definidas;
- visibilidade/permissões estão claras;
- critérios de aceite existem;
- questões críticas de produto foram resolvidas;
- estados principais da experiência foram considerados;
- dependências conhecidas foram identificadas.

Nem todas as features precisam cumprir todos os itens. O objetivo não é criar um processo burocrático, e sim evitar começar a implementação com decisões fundamentais ainda indefinidas.
